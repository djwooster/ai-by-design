## Feedback that shaped the current design (Oct 28)
- Sections need imagery to tell the story: text on one side and an image on the other, or a grid of images. Never a giant heading on its own.
- The curriculum must be scannable with nothing to click.
- Prefer illustrative drawings to literal UI mockups for supporting sections.
